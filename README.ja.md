# CircuitJS1

CircuitJS1はブラウザ上で動作する電子回路シミュレータです。もともとはPaul FalstadによってJavaアプレットとして開発され、その後Iain SharpによってGWTを使用してブラウザ上で動作するように移植されました。

## デモ

ホストされているアプリケーションについては、以下を参照してください:

- **Paulのページ:** [http://www.falstad.com/circuit/](http://www.falstad.com/circuit/)
- **Iainのページ:** [http://lushprojects.com/circuitjs/](http://lushprojects.com/circuitjs/)

## 機能

- **ブラウザベース:** インストール不要で、最新のブラウザであればどれでも動作します。
- **豊富なコンポーネントライブラリ:** 多種多様な受動部品、能動部品、デジタルチップ、カスタムビルディングブロックが含まれています。
- **カスタムロジックとサブサーキット:** カスタムロジックデバイスを設計して再利用したり、既存の回路図から「ブラックボックス」化されたサブサーキットを作成できます。
- **回路の共有:** 作成したカスタム回路のリンクを簡単に作成して共有できます。
- **学習用サンプル:** 教育目的で利用できる、あらかじめ作成されたサンプル回路が多数用意されています。
- **WebSocketインターフェース:** シミュレーションのリモート制御や自動化、コンポーネントの値の読み取り、回路図のエクスポートが可能です。
- **デスクトップアプリケーション:** Electronで構築された、クロスプラットフォーム対応のデスクトップ版が利用可能です。
- **多言語対応:** 複数の言語をサポートしており、新しい翻訳を追加するための手順も用意されています。

## 開発セットアップ

このプロジェクトは、ローカル環境またはクラウドベースの開発環境でビルドできます。

### クラウド開発（推奨）

最も簡単な始め方は、このプロジェクト用に事前設定されたクラウド開発環境を使用することです。

1.  [GitHub Codespaces](https://github.com/features/codespaces) または [Gitpod](https://www.gitpod.io/) でこのリポジトリを開きます。
2.  `dev.sh setup` スクリプトによって環境が自動的にセットアップされます。
3.  セットアップが完了したら、`dev.sh start` で開発サーバーを起動します。

### ローカル開発

**前提条件:**
*   Java Development Kit（OpenJDK 8 を推奨）
*   Apache Ant
*   Google Web Toolkit (GWT) バージョン 2.8.2

**手順:**

1.  リポジトリをクローンします。
2.  セットアップスクリプトを実行してGWTをダウンロードし、ビルド環境を設定します。このスクリプトは、DebianベースのシステムでJavaやAntが見つからない場合、それらのインストールを試みます。
    ```bash
    ./dev.sh setup
    ```
3.  GWTコードサーバーとローカルWebサーバーを起動します:
    ```bash
    ./dev.sh start
    ```
    アプリケーションは `http://127.0.0.1:8000` で利用できるようになります。

## 使い方

`dev.sh` スクリプトには、プロジェクトを管理するためのいくつかのコマンドが用意されています:

-   `./dev.sh setup`: 依存関係をインストールし、ビルド設定を行います。
-   `./dev.sh start`: 開発用のGWTコードサーバーとローカルWebサーバーを起動します。
-   `./dev.sh compile`: JavaソースコードをJavaScriptにコンパイルします。
-   `./dev.sh package`: プロジェクトをコンパイルし、ルートディレクトリに `circuitjs1.tar.gz` アーカイブを作成します。

## 高度な機能

### WebSocketインターフェース

CircuitJS1は、リモート制御と自動化のためのWebSocketインターフェースをサポートしています。これにより、任意のプログラミング言語からシミュレーションの開始/停止、ノード電圧の読み取り、外部電圧源の設定、回路図のエクスポートが可能になります。

詳細なドキュメントと例については、[WebSocketインターフェースのREADME](websocket/README.md) を参照してください。

### デスクトップアプリケーション

`app/` ディレクトリにデスクトップ版が用意されています。実行するには以下のコマンドを使用します:

```bash
cd app
# 依存関係をインストール（一度だけ実行）
# npm install
# アプリケーションを起動
npm start
```

### 埋め込み

シミュレータは `<iframe>` を使用して他のWebページに埋め込むことができます。`jsinterface.html` ファイルには、JavaScriptを使用して親ページからシミュレータとやり取りする方法の詳細な例が含まれています。

### 翻訳への貢献

新しい翻訳の提供を歓迎します。始めるには、[langディレクトリのREADME](lang/README.md) に記載されている手順を参照してください。
